# いびきログ

Pixel 10 Pro XL / Android 17 で使う、端末内で完結する夜間録音アプリ。

## 最初の版の目標

- 寝る前に開始し、画面を消しても録音を継続する。
- 音のある区間を「いびき候補」として前後の余白付きで保存する。
- 夜全体の時刻付きタイムライン、区間ごとの波形、再生を用意する。
- AAC / M4A 音声と、解析用の JSON / CSV を ZIP にまとめて書き出す。
- 録音の中断を無音と混同せず記録する。
- 初期版は充電しながらの利用を想定し、実機で安定性と電池消費を測る。

音量による検出だけでは寝返り・会話・環境音を区別できないため、初期版の表示は「いびき候補」とする。音の分類の精度は実際の寝室の録音で評価する。

## 開発

Android CLI による雛形作成、Gradle によるビルド、Android CLI / ADB による端末確認を試す。開発環境・確認手順・確認結果は実装に合わせて追記する。

音声・個人の計測データ・開発ツール本体・ビルド成果物は Git に含めない。
