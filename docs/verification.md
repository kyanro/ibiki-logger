# 動作確認

2026-09-27、Windows + Pixel 10 Pro XL（Android 17 / API 37）。

## 確認済み

- Android CLI 1.0.16406183 による雛形生成。
- GradleでAPK生成、Android CLIで実機インストール・起動。
- Android CLIによる実機のスクリーンショットとUI構造の取得。
- 単体テスト5件成功：8時間相当の無音入力、前後余白と絶対位置、継続音の分割、中断をまたがない区間、音量計算。
- 実機テスト3件成功：YAMNetで無音を非いびきと判定、AAC保存・時刻・ZIP整合性、マイク録音を画面消灯中も継続して正常停止。
- 実操作：約32秒を音量モードで録音、3区間を保存、波形表示と再生、システムの保存画面でダウンロードにZIP保存、PCへ取り出し。
- 上記ZIPに音声3本・session.json・clips.csv・waveform.csv・README.txtが揃うことを確認。ZIPサイズ約51 KB。
- アプリIDを `com.kyanro.ibiki_logger` に統一後、再ビルド・実機インストール、モデル判定とAAC・ZIPの実機テスト2件を再確認。
- 新しいIDで標準感度・音量モードオフの実録音を52.1秒実施。正常終了、欠落区間なし、候補音声0件を確認。実際のいびきに対する検出精度の評価は含まない。
- 波形を区間ごとに保存する方式へ変更後も、ZIP内の波形・音声・時刻の整合性を確認。通常の経過情報は30秒間隔で保存。
- Lintのエラー0。ライブラリの新バージョン案内などの警告は残る。

自動テストの8時間入力は検出処理のシミュレーション。8時間の実機録音が完了したという意味ではない。テスト音声・端末画面・APKはGit対象外。

## 0.1.1：BGMとライセンス

- sim-speed-viewerと同じ「にゃーにゃーにゃー」のMP3を同梱。APK内のSHA-256も権利表示の値と一致。
- 指定された曲紹介ページが「にゃーにゃーにゃー — Wabigashi Fumi | OTOGI SHIFT」を表示することを確認。READMEとアプリのリンク先に採用。
- Pixel上の追加テスト3件成功：MP3の読み取りとライセンス文書の同梱、BGM再生中の録音開始で停止・録音中の再生無効・録音終了後の自動再生なし、アプリを離れると停止・戻っても自動再生なし。
- ビルド、既存の単体テスト5件、Lint成功。実機は既存の記録を維持する上書き更新で0.1.1に更新。
